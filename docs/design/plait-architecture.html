Plait — rankless consensus-fused fabric

Equal peers · EPaxos-style ordering · fused runtime · descriptors + one-sided RDMA · no rank 0

Key decisions

  • • EPaxos-style leaderless log, not a permanent leader
  • • 3–8 voter domains, not one 512-voter quorum
  • • shard-level batched commands, not per-query ops
  • • descriptors + rdma-io for bulk, not tensor bytes in the log
  • • device capability + Mode::Compute, not a rank-implied vendor

Failure stance

  • • minority partition: reject new commits, serve last executed
  • • proposer crash: any voter recovers with a higher ballot
  • • membership change: unanimous, deliberately unavailable
  • • RDMA QP loss: bound poll, teardown/reconnect, do not fake commit

Next scale trigger

  • • >20k commands/s or commit p99 >10 ms
  • • domain fanout >8 voters
  • • move to per-domain groups + compaction
  • • then benchmark on Soft-RoCE/RNIC hardware
